## For Claude

Use the six sheets as visual references, not as finished sprite sheets or 3D models. Do not import an entire contact sheet as one in-game object. Crop panels for temporary UI placeholders if useful, then create or source separate production assets with correct pivots, scale, collisions, animations, and team-color handling. For a 3D game, build real meshes or use properly licensed 3D models; for a 2D/isometric game, create individual sprites with consistent angles and movement/firing/death states.

The generated rank boards are visual concepts, not an authoritative chart of current Iranian rank insignia. The equipment depictions are also stylized references; validate silhouettes before treating a panel as an exact model. Use fictionalized faction balance values and avoid presenting speculative equipment status as fact.

## Included generation approach

Generated with the built-in image-generation tool as six separate, non-transparent catalog sheets. The sheets are raster reference art; no Blender models or production-ready sprite atlases are included.
